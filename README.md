# CandyWebGL

Some test with WebGL

## 项目说明

1. 对WebGL官网的实例的一些改动
2. 对three.js的一些小测试
3. WebGPU新一代图形API示例
4. Canvas 2D CAD绘图工具
5. 3D函数可视化绘图
6. 宇宙模拟器、粒子效果等多种3D可视化

## 项目结构

- **MainFunction/** - 主要功能导航（中文命名，整理后的功能合集）
  - 模型加载器/ - 各种3D模型格式加载（PLY、PCD、STL、OBJ、FPX等）
  - CAD工具/ - 专业CAD绘图和函数绘图
  - 3D可视化/ - 粒子文本、无人机表演、立体文字、太极图、宇宙模拟器
  - 图形API/ - WebGPU新一代图形API示例
  - 实验项目/ - 光照实验、齿轮传动仿真
  - 图元编辑/ - WebGL图元编辑器

- **page/** - 原始功能页面（保持原样）
  - 包含各种3D模型加载器、CAD工具、可视化效果等

- **study/** - WebGL学习教程
  - 第一章：2D图形基础
  - 第二章：变换与3D基础
  - 第三章：光照与场景

## 导航

- 主index.html提供MainFunction和study的导航入口
- MainFunction/导航.html - 主要功能完整导航
- page/导航.html - page文件夹功能导航
- study/导航.html - 学习教程导航

## 技术栈

- WebGL / WebGL2
- Three.js
- WebGPU (WGSL着色器)
- Canvas 2D
- HTML5 / CSS3 / JavaScript
