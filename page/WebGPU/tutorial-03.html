1. 纹理的基本概念

纹理是存储在 GPU 内存中的图像数据，可以用来为 3D 模型表面添加细节。纹理映射需要：

  • 纹理图像: 通常是 2D 图像（JPG/PNG/WebP）
  • UV 坐标: 顶点上的纹理坐标 (0-1 范围)
  • 采样器: 定义如何从纹理中采样像素
// 加载纹理并创建 GPU 纹理 async function loadTexture(url) { const response = await fetch(url); const blob = await response.blob(); const img = await createImageBitmap(blob); const texture = device.createTexture({ size: [img.width, img.height], format: 'rgba8unorm', usage: GPUTextureUsage.TEXTURE_BINDING | GPUTextureUsage.COPY_DST | GPUTextureUsage.RENDER_ATTACHMENT }); device.queue.copyExternalImageToTexture( { source: img }, { texture: texture }, [img.width, img.height] ); return texture; }

2. 采样器配置

采样器控制纹理的读取方式，包括：

  • 寻址模式: wrap(重复)、clamp(截断)、mirror(镜像)
  • 过滤模式: nearest(最近邻)、linear(线性)
  • Mipmap: 多级渐远纹理
// 创建采样器 const sampler = device.createSampler({ addressModeU: 'repeat', addressModeV: 'repeat', magFilter: 'linear', minFilter: 'linear', mipmapFilter: 'linear' });

3. 在着色器中使用纹理

通过绑定组将纹理和采样器传递给着色器，然后在片段着色器中采样。

// 片段着色器中的纹理采样 struct FragmentInput { @location(0) uv: vec2, }; @group(0) @binding(0) var mySampler: sampler; @group(0) @binding(1) var myTexture: texture_2d; @fragment fn main(input: FragmentInput) -> @location(0) vec4 { // 使用采样器和UV坐标采样纹理 let color = textureSample(myTexture, mySampler, input.uv); return color; }
