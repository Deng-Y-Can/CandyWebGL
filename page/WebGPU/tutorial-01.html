1. WebGPU 架构概览

WebGPU 是新一代 Web 图形 API，提供了更底层的 GPU 控制能力。核心组件包括：Adapter（适配器）、Device（设备）、Render Pipeline（渲染管线）、Command Buffer（命令缓冲区）。

2. 初始化流程

WebGPU 应用的标准初始化流程：

  • 检查浏览器支持: navigator.gpu
  • 获取适配器: requestAdapter()
  • 获取设备: requestDevice()
  • 配置 Canvas 上下文
// WebGPU 初始化核心代码 async function initWebGPU() { // 检查支持 if (!navigator.gpu) throw new Error("不支持 WebGPU"); // 获取适配器（GPU硬件） const adapter = await navigator.gpu.requestAdapter(); const device = await adapter.requestDevice(); // 获取 Canvas 上下文 const context = canvas.getContext('webgpu'); const format = navigator.gpu.getPreferredCanvasFormat(); // 配置上下文 context.configure({ device, format }); }

3. 渲染管线与着色器

渲染管线定义了图形渲染的完整流程，包含顶点着色器和片段着色器。使用 WGSL（WebGPU Shading Language）编写。

// 顶点着色器 - 处理顶点位置 const vertexShader = ` struct VertexInput { @location(0) position: vec2, @location(1) color: vec3, }; struct VertexOutput { @builtin(position) position: vec4, @location(0) color: vec3, }; @vertex fn main(input: VertexInput) -> VertexOutput { var output: VertexOutput; output.position = vec4(input.position, 0.0, 1.0); output.color = input.color; return output; } `; // 片段着色器 - 处理像素颜色 const fragmentShader = ` @fragment fn main(@location(0) color: vec3) -> @location(0) vec4 { return vec4(color, 1.0); } `;

4. 命令提交流程

WebGPU 采用异步命令提交模式：创建命令编码器 → 记录渲染命令 → 完成命令缓冲区 → 提交到 GPU 队列执行。

// 渲染循环核心代码 function render() { // 创建命令编码器 const encoder = device.createCommandEncoder(); // 开始渲染通道 const pass = encoder.beginRenderPass({ colorAttachments: [{ view: context.getCurrentTexture().createView(), loadOp: 'clear', storeOp: 'store', clearValue: [0.05, 0.05, 0.08, 1.0] }] }); // 设置管线和缓冲区 pass.setPipeline(pipeline); pass.setVertexBuffer(0, vertexBuffer); pass.draw(3); // 绘制3个顶点 // 结束并提交 pass.end(); device.queue.submit([encoder.finish()]); }

⚙️ 关键概念

Adapter: 代表 GPU 硬件适配器

Device: GPU 逻辑设备，用于创建资源

Pipeline: 渲染管线，定义渲染流程

Command Queue: 命令队列，异步执行 GPU 命令
