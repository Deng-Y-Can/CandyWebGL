1. 粒子系统架构

粒子系统通常包含三个阶段：

  • 发射阶段: 创建新粒子并设置初始属性
  • 更新阶段: 更新粒子位置、速度、生命周期
  • 渲染阶段: 将粒子绘制到屏幕上

在 WebGPU 中，可以使用 计算着色器 来并行更新大量粒子。

// 计算着色器中的粒子更新 struct Particle { position: vec3, velocity: vec3, life: f32, color: vec4, }; @group(0) @binding(0) var particles: array; @compute @workgroup_size(64) fn updateParticles(@builtin(global_invocation_id) id: vec3) { let i = id.x; if (i >= arrayLength(&particles)) { return; } var p = particles[i]; // 更新位置 p.position += p.velocity * 0.01; // 应用重力 p.velocity.y -= 0.001; // 更新生命周期 p.life -= 0.002; // 如果粒子死亡，重新发射 if (p.life <= 0.0) { p.position = vec3(0.0, 0.0, 0.0); p.velocity = vec3( (f32(id.x) * 0.1 - 5.0), 5.0 + f32(id.x) * 0.01, (f32(id.x) * 0.1 - 5.0) ); p.life = 1.0; } particles[i] = p; }

2. 粒子渲染策略

常用的粒子渲染方法：

  • 点精灵 (Point Sprites): 使用点绘制，适合大量小粒子
  • 四边形 (Quads): 使用 Billboard 技术，适合有方向的粒子
  • 几何体: 使用 3D 几何体，适合大粒子
// 顶点着色器中的点精灵大小控制 @vertex fn main(input: VertexInput) -> VertexOutput { var output: VertexOutput; // 计算屏幕空间位置 let viewPos = uniforms.view * vec4(input.position, 1.0); // 根据距离调整粒子大小（透视校正） let scale = 20.0 / -viewPos.z; output.position = uniforms.projection * viewPos; output.size = input.size * scale; output.color = input.color; return output; }
