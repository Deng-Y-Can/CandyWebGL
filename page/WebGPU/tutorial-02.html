1. MVP 变换链

3D 渲染的核心是坐标变换。MVP 代表：

  • Model（模型矩阵）: 将模型从局部空间转换到世界空间
  • View（视图矩阵）: 将世界空间转换到相机空间
  • Projection（投影矩阵）: 将相机空间转换到裁剪空间

最终变换: clipPos = projection * view * model * localPos

// 创建透视投影矩阵 function createPerspective(fov, aspect, near, far) { const f = 1.0 / Math.tan(fov / 2); const nf = 1.0 / (near - far); return new Float32Array([ f / aspect, 0, 0, 0, 0, f, 0, 0, 0, 0, (far + near) * nf, -1, 0, 0, 2 * far * near * nf, 0 ]); } // 创建视图矩阵（相机位置和朝向） function createViewMatrix(eye, center, up) { const z = normalize(subtract(eye, center)); const x = normalize(cross(up, z)); const y = cross(z, x); return new Float32Array([ x[0], y[0], z[0], 0, x[1], y[1], z[1], 0, x[2], y[2], z[2], 0, -dot(x, eye), -dot(y, eye), -dot(z, eye), 1 ]); }

2. 模型矩阵的组成

模型矩阵通常由平移、旋转、缩放三个变换组合而成：

model = translate * rotateX * rotateY * rotateZ * scale

// 创建绕Y轴旋转的模型矩阵 function createModelMatrix(rotationY, rotationX) { const c1 = Math.cos(rotationY), s1 = Math.sin(rotationY); const c2 = Math.cos(rotationX), s2 = Math.sin(rotationX); return new Float32Array([ c1, 0, s1, 0, s1*s2, c2, -c1*s2, 0, -c1*s2, s2, c1*c2, 0, 0, 0, 0, 1 ]); }

3. 着色器中的 MVP 变换

在顶点着色器中应用完整的 MVP 变换链，将局部坐标转换为裁剪坐标。

// 顶点着色器中的 MVP 变换 struct Uniforms { model: mat4x4, view: mat4x4, projection: mat4x4, }; @group(0) @binding(0) var uniforms: Uniforms; @vertex fn main(input: VertexInput) -> VertexOutput { var output: VertexOutput; // MVP 变换链 let modelPos = uniforms.model * vec4(input.position, 1.0); let viewPos = uniforms.view * modelPos; output.position = uniforms.projection * viewPos; output.color = input.color; return output; }

⚙️ 关键概念

模型空间: 模型自身的局部坐标系

世界空间: 所有对象共享的全局坐标系

相机空间: 以相机为原点的坐标系

裁剪空间: 标准化设备坐标系
