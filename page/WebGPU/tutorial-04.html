1. Phong 光照模型

Phong 光照模型是计算机图形学中经典的光照模型，包含三个组成部分：

  • 环境光 (Ambient): 均匀照亮物体的背景光
  • 漫反射 (Diffuse): 粗糙表面的散射光
  • 镜面反射 (Specular): 光滑表面的高光反射

总光照 = 环境光 + 漫反射 + 镜面反射

// Phong 光照公式 // 环境光: I_ambient = k_a * I_a // 漫反射: I_diffuse = k_d * I_l * max(0, n · l) // 镜面反射: I_specular = k_s * I_l * max(0, r · v)^shininess // 其中: // k_a, k_d, k_s = 材质系数 // I_a, I_l = 环境光和光源强度 // n = 法线向量 // l = 光源方向 // r = 反射方向 // v = 视角方向

2. 法线向量的重要性

法线向量决定了表面的朝向，是计算光照的关键。对于平滑着色，需要为每个顶点计算法线；对于平面着色，可以使用面法线。

// 片段着色器中的 Phong 光照计算 @fragment fn main(input: FragmentInput) -> @location(0) vec4 { // 归一化法线 let normal = normalize(input.normal); // 光源方向（从表面指向光源） let lightDir = normalize(uniforms.lightPos - input.position); // 视角方向 let viewDir = normalize(-input.position); // 反射方向 let reflectDir = reflect(-lightDir, normal); // 环境光 let ambient = uniforms.ambientColor * 0.3; // 漫反射 let diffuse = max(dot(normal, lightDir), 0.0); let diffuseColor = uniforms.diffuseColor * diffuse; // 镜面反射 let specular = pow(max(dot(viewDir, reflectDir), 0.0), 32.0); let specularColor = uniforms.specularColor * specular; // 最终颜色 let finalColor = ambient + diffuseColor + specularColor; return vec4(finalColor, 1.0); }

3. 着色方式对比

平滑着色 (Gouraud): 在顶点着色器中计算光照，然后插值到片段

Phong 着色: 在片段着色器中计算光照，效果更好但性能开销更大

⚙️ 关键概念

法线向量: 垂直于表面的单位向量

光照方向: 从表面指向光源

反射方向: 光线反射后的方向

高光指数: 控制高光的锐利程度
